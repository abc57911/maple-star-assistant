# 小地圖巡航原地位移技後搖

> 知識庫索引：[../../INDEX.md](../../INDEX.md)

## 背景

小地圖巡航偵測角色停止前進滿 `1 秒`後，可施放「原地位移技」。現行流程在技能鍵放開後立即恢復停滯追蹤；技能期間若角色超出邊界，系統也會提前放開技能鍵並立即轉向。遊戲在位移技結束後仍有短暫後搖，這兩種行為都可能過早觸發。

## 目標

- 原地位移技固定按滿既有 `0.8 秒`。
- 技能鍵放開後保留固定 `0.2 秒`後搖。
- 角色未超界時，技能鍵放開後立即恢復攻擊，但在後搖結束後才開始新的 `1 秒`停滯計時。
- 角色超界時，技能鍵放開後維持攻擊鍵放開，後搖結束後才轉向。
- 左右巡航與左右超界採相同時序。

## 非目標

- 不調整邊界前技能。
- 不新增 GUI、設定欄位或 profile 資料。
- 不改變原地位移技的 `0.8 秒`按住時間。
- 不修改 `_begin_turn()` 內既有轉向、方向鍵按住及恢復攻擊的相對時序；本功能只在進入 `_begin_turn()` 前增加 `0.2 秒`等待。
- 不把後搖時間套用到一般停滯轉向、邊界轉向或 recovery。

## 設計

### 狀態資料

在 `maple_star/services/minimap_cruise.py` 新增固定常數：

```python
MINIMAP_CRUISE_STATIONARY_SKILL_POST_DELAY_SECONDS = 0.2
```

`MinimapCruiseRuntime` 新增 `stationary_skill_post_delay_until`，保存原地位移技後搖的截止時間。流程沿用 `MINIMAP_CRUISE_STATUS_STATIONARY_SKILL`，不新增公開狀態或狀態文字。

### 執行順序

原地位移技分成三個階段：

1. **技能按住**
   - 放開攻擊鍵並按住技能鍵。
   - 清除舊的 `stationary_x` 與 `stationary_started_at`。
   - 即使角色在技能期間超界，也不提前放開技能鍵或轉向。
   - 技能鍵固定按滿 `0.8 秒`。
2. **後搖等待**
   - 放開技能鍵，設定後搖截止時間為目前時間加 `0.2 秒`。
   - 立即擷取角色位置。
   - 角色仍在邊界內時立即恢復攻擊；角色已超界時維持攻擊鍵放開。
   - 首次擷取失敗時立即暫停巡航、釋放按鍵並清除後搖 deadline。
   - 後搖期間不執行停滯追蹤或轉向；`stationary_x` 與 `stationary_started_at` 維持 `None`。
3. **後搖結束**
   - 再次擷取角色位置。
   - 角色超界時，呼叫既有 `_begin_turn()`，後續沿用既有 recovery 流程。
   - 角色仍在邊界內時，以當下位置與時間建立新的停滯追蹤基準，並回到攻擊狀態。

技能鍵放開時或後搖截止時若找不到角色點，皆沿用巡航主迴圈的安全行為：暫停巡航、釋放按鍵、清除後搖 deadline，並回報找不到角色點。

後搖截止時的第二次擷取決定最終動作。角色可能在等待期間改變邊界狀態：

- 放開技能鍵時在界內、後搖結束時超界：先立即恢復攻擊，截止時再放開攻擊並轉向。
- 放開技能鍵時超界、後搖結束時已回到界內：等待期間維持攻擊鍵放開，截止時恢復攻擊並建立新的停滯基準。

### 清理

`_cancel_stationary_skill()` 同時清除技能鍵與後搖截止時間。停止、失去前景、測謊暫停及其他既有取消路徑繼續透過此 helper 釋放狀態，避免殘留技能鍵或延遲動作。

## 影響範圍

- `maple_star/services/minimap_cruise.py`
  - 新增固定後搖常數與 runtime deadline。
  - 把原地位移技更新流程拆成按住、後搖與完成三個階段。
  - 移除技能期間超界便提前轉向的行為。
- `tests/test_minimap_cruise.py`
  - 更新原地位移技正常結束測試。
  - 更新技能期間超界測試。
  - 補上後搖前後的攻擊、停滯計時與左右轉向案例。

## 驗收條件

- 原地位移技在技能期間超界仍按滿 `0.8 秒`。
- 未超界時，技能鍵放開後立即恢復攻擊。
- 技能鍵放開後未滿 `0.2 秒`時，`stationary_started_at` 尚未開始新的計時。
- 後搖滿 `0.2 秒`後，未超界角色才建立新的停滯追蹤基準。
- 後搖滿 `0.2 秒`前不會因位移技超界而按下轉向鍵。
- 後搖滿 `0.2 秒`後，右側超界向左轉，左側超界向右轉。
- 放開技能鍵時在界內、截止時超界，最終依截止時位置轉向。
- 放開技能鍵時超界、截止時回到界內，最終依截止時位置恢復攻擊。
- 後搖在 `now >= deadline` 時完成；截止點前不執行最終動作。
- stop、suspend 或測謊中斷會清除後搖 deadline 並釋放相關按鍵。
- 既有邊界前技能與 out-of-bounds recovery 測試維持通過，確認後搖只影響原地位移技。
