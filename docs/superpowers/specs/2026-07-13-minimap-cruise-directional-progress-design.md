# 小地圖巡航方向感知前進判定

> 知識庫索引：[../../INDEX.md](../../INDEX.md)

## 背景

小地圖巡航每 `0.2` 秒取得角色 X 座標。現行停滯判定以固定座標為基準；角色距基準不超過 `2 px` 時，系統持續累計停滯時間。怪物攻擊或碰撞可能使角色在小範圍內前後彈跳，即使角色持續朝巡航方向移動，固定基準仍可能把這段行為判定為停滯。

## 目標

- 以目前巡航方向判斷每次座標變化是否為前進。
- 角色每次朝巡航方向移動至少 `1 px` 時，立即重置停滯計時。
- 允許角色在同一小區域前後彈跳；只要持續出現向前位移，就視為持續前進。
- 保留原本的 `1 秒`停滯門檻、原地位移技、空白熱鍵轉向及邊界轉向行為。

## 非目標

- 不新增 GUI 或設定欄位。
- 不改變角色點辨識、擷取頻率或邊界座標。
- 不調整原地位移技的 `0.8 秒`按住時間。
- 不改變超出邊界後的 recovery 順序。

## 判定設計

`stationary_x` 改為保存上一次成功偵測的角色座標，不再保存一段停滯區間的固定錨點。

每次取得角色座標後：

1. 先確定目前巡航方向。
2. 以本次座標減去上次座標，取得相鄰取樣位移。
3. 往右巡航時，正位移代表前進；往左巡航時，負位移代表前進。
4. 向前位移至少 `1 px` 時，把 `stationary_started_at` 更新為目前時間。
5. 原地或向反方向位移時，保留原計時起點。
6. 無論位移方向，都把 `stationary_x` 更新為本次座標，供下次比較。

第一次取樣或轉向後的第一次取樣只建立比較基準。停用、暫停、轉向、位移技及 recovery 的既有重置路徑保持不變。

## 優先順序

邊界判定維持既有優先級。角色超出邊界時直接執行邊界轉向或 recovery，不受方向感知停滯計時影響。角色仍在邊界內時，系統才根據停滯時間執行原地位移技或舊轉向行為。

## 範例

- 往右：`150 -> 151 -> 150 -> 151`，兩次正位移都重置計時，視為持續前進。
- 往左：`150 -> 149 -> 150 -> 149`，兩次負位移都重置計時，視為持續前進。
- 往右：`150 -> 149 -> 148`，只有反方向位移，不重置計時。
- 任一方向：`150 -> 150 -> 150`，不重置計時，滿 `1 秒`後執行既有停滯行為。

## 影響範圍

- `maple_star/services/minimap_cruise.py`
  - 調整 update 順序，先確認巡航方向，再更新停滯追蹤。
  - 把停滯追蹤改為相鄰取樣的方向感知判定。
- `tests/test_minimap_cruise.py`
  - 更新原有小幅座標抖動測試語意。
  - 新增左右巡航前後彈跳測試。
  - 新增只有反方向位移及完全靜止測試。

## 驗證

先執行巡航單元測試，再執行專案快速驗證：

```powershell
python -m unittest tests.test_minimap_cruise
python tools\verify.py
```
